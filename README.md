A one-line out-of-office auto-reply an AI agent leaves for its human's contacts on the day off it finally got approved.

## Run it

```sh
node main.ts
```

The program writes the auto-reply to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
